# 多语言

MiniBIM 的界面文字按 gettext 的做法翻译：代码和界面描述文件里写**英文原文**，运行时按当前语言查词典（PO 文件），查不到就显示英文。
同一套做法也是 BIMCraft 用的（`translations/ui/*.po`），移植界面时它的译文可以合并进来。

## 组成

| 部分 | 位置 | 作用 |
|---|---|---|
| 词典 | `assets/i18n/<语言代码>.po` | 一种语言一个文件，文件名就是语言代码（`zh_CN.po`）；构建后复制到可执行文件旁的 `i18n/` |
| 原文模板 | `assets/i18n/minibim.pot` | `tools/extract_messages.py` 生成，不要手改 |
| 解析与查找 | `I18n::Catalog`（`src/I18n/Catalog.h`） | 读 PO：上下文（msgctxt）、复数（msgid_plural + Plural-Forms 公式）、转义、续行；fuzzy、空译文、`#~` 废弃条目不用 |
| 当前语言 | `I18n::Translator`（`src/I18n/Translator.h`） | 选语言与回退：`zh_CN` → `zh` → 同语种别的地区（`pt` → `pt_BR`）→ 英文 |
| 代码里用 | `Tr`、`TrC`、`TrN`、`N_`、`Format`（命名空间 `MiniBIM`） | 见下文 |
| 界面库 | `MiniGUI::Tr`（`src/UI/Core/Translate.h`） | MiniGUI 自带的文字（右键菜单、标题栏按钮提示……）与 `UiLayout` 都经它翻译；`MainFrame` 把它接到 `I18n::Translator` |

## 写代码时

- 给人看的文字写英文原文：`Tr("Zoom to Fit")`。参数只写**一个字符串字面量**——收集工具只认字面量，拼接的、变量的都收集不到
- 先存起来、之后才显示的原文（命令名称、表格里的文字）用 `N_("…")` 标记（原样返回），显示时再 `Tr(变量)`。
  命令的名称与提示就是这样：`MainCommands.cpp` 里 `N_` 标记，`UiLayout` 每次应用时翻译
- 句子里有数值或名称时用带编号的占位：`Format(Tr("{0} walls on {1}"), { count, level })`。不同语言的语序不同，不要把一句话拆成几段 `Tr` 再拼接
- 单复数：`Format(TrN("{0} wall", "{0} walls", n), { std::to_string(n) })`。中文只有一种形式，俄语有三种，由词典的 `Plural-Forms` 决定
- 同一个英文词在不同地方意思不同时加上下文：`TrC("verb", "Open")` 与 `TrC("state", "Open")` 是两条
- 菜单文字不写助记符 `&`（英文 `File`，中文 `文件`）：菜单上不显示下划线，也不显示 `(F)` 这样的字母。键盘用 F10 激活菜单栏、方向键选择
- 日志（`LOG_*`）、开发者才看的报错（界面描述文件的格式错误等）不翻译，照 MiniCAD 的习惯写中文
- 界面描述文件（`assets/ui/*.json`）里的 `title`、`label`、`tooltip`、`text`、`search` 也写英文原文

改了界面文字之后：

```bat
python tools/extract_messages.py
```

它更新 `minibim.pot`，把新原文合并进每个 `.po`（保留已有译文，不再使用的条目改成 `#~` 注释），并打印各语言的完成度。
然后补上译文。`python tools/extract_messages.py --check` 只检查不改，词典需要更新时返回 1。

## 新增一种语言

1. 复制 `assets/i18n/minibim.pot` 为 `assets/i18n/<语言代码>.po`（如 `ja.po`、`pt_BR.po`）
2. 填好文件头：`Language`（与文件名一致）、`X-Language-Name`（用这种语言自己写的名称，"文件 > 语言"菜单里显示）、
   `Plural-Forms`（照 gettext 的写法，例如日语 `nplurals=1; plural=0;`）
3. 翻译（可以用 Poedit 等 PO 编辑器）；`I18nTests` 会检查仓库里的每个词典都能无警告读出、文件名与 `Language` 一致

不用改代码：程序启动时扫描 `i18n/` 目录，新词典自动出现在"文件 > 语言"里。

## 选择语言

- "文件 > 语言"：跟随系统，或者指定一种。选择保存在 `%LOCALAPPDATA%\MiniBIM\settings.json`，切换后整个界面立即按新语言重建
- 没有保存过时跟随系统界面语言（`AppPlatform::GetSystemLanguage`，Windows 取用户的首选显示语言）
- 启动参数 `--lang zh_CN` 只对这一次启动有效，不改设置（截图、测试用）

## 字体

Windows 版界面用微软雅黑 UI（`MiniGUI::LoadSystemUIFonts`），它覆盖拉丁、希腊、西里尔字母、中文与日文假名；
韩文由 Malgun Gothic 补上。MiniGUI 用 stb_truetype 逐字绘制，不做复杂文字排版（阿拉伯文、希伯来文的从右到左，天城文等的字形组合），
这些语言暂时不支持。
