MiniBIM 0.2.0 is the first release that models buildings. Since 0.1.0 (the skeleton copied from MiniCAD), BIMCraft's model, its
interface and the rest of its ribbon tabs have been ported to C++, and MiniBIM now runs on Windows, Linux and in the browser.

## Downloads

| Platform | File | Graphics |
|---|---|---|

## What's new

**Model** (ported from BIMCraft `crates/core`)
- Levels, grids, walls (layered types, joins, openings), floors, ceilings, roofs (footprint and extrusion), rooms and room separators,
  doors, windows, families and components with their formulas and swept / revolved / void forms, materials
- Every edit is a command with undo; projects save as `.minibim`, the same format as BIMCraft's `.bimcraft`, which each opens
- 3D view modelled with the SMLib solid kernel; plans of each level with cut fills, single-line text and picking
- IFC: IFC4 export, IFC2x3 / IFC4 import
- Revit projects (`.rvt`) open read-only: walls, floors, ceilings, roofs, doors and windows, rooms and columns, with a report of what was left out.
  The Revit reader is Apache-2.0 (ported from BIMCraft's `crates/rvt`, which contains rvt-rs code); the rest of MiniBIM is MIT

**Interface** (ported from BIMCraft `crates/ui-egui`)
- Ribbon, properties and project browser panels that dock or float (floating or compact layout), quick access toolbar
- Placing tools with snaps, previews and the options bar; modify tools: window / crossing selection, drag, grips, move, copy, rotate,
  mirror, align, trim, split, offset
- Type properties, family types and materials dialogs; sketch mode for floor, ceiling and roof boundaries
- Start page, recent files, autosave and recovery, settings, two-letter shortcuts, drag a file onto the window to open it
- English, Simplified Chinese, Spanish and Portuguese

**The other ribbon tabs**
- Structure: beams, isolated and wall foundations, structural columns
- Plumbing, Electrical, Lightning Protection and Data: runs (pipes, ducts, conduits, cable trays…) and their devices
- Massing: masses, mass floors, walls / floors / roofs by face, lofts
- Annotate: dimensions, text, spot elevations, tags, detail lines, filled regions, measure
- View: visibility / graphics overrides, plan views and duplicates, view templates and filters, schedules (CSV), sections, elevations,
  sheets and viewports
- Manage: project parameters, line weights, object styles, line styles, line patterns, fill patterns (PAT import and export), purge unused
- Insert: link models (`.minibim`, `.bimcraft`, `.ifc`), insert from file, DXF import and link (layers, colours, linetypes, snaps),
  point clouds (PTS, XYZ, PLY, LAS, E57) drawn in the 3D view and the plans and snapped to

**Platforms**
- Linux build (SDL3, Vulkan / OpenGL ES 3) and web build (Emscripten, WebGPU / WebGL 2); CI builds, tests and packages all three

## Not yet

- Sections and elevations don't show point clouds; LAZ, ReCap and DWG files aren't read (save them as LAS, E57 or DXF)
- Stairs, ramps, railings, groups, phases and design options aren't ported yet
- The full list of what's done and what's left is in [docs/PLAN.md](https://github.com/CHMOSE023/MiniBIM/blob/main/docs/PLAN.md) (in Chinese)

## 简体中文

MiniBIM 0.2.0 是第一个能建模的版本。从 0.1.0（复制自 MiniCAD 的骨架）以来，移植了 BIMCraft 的模型、界面与其余各个选项卡，
并有了 Windows、Linux 与网页三个版本。

### 下载

| 平台 | 文件 | 图形接口 |
|---|---|---|
| Windows x64 | `MiniBIM-v0.2.0-windows-x64.zip` | Direct3D 12 / Direct3D 11 |
| Linux x64 | `MiniBIM-v0.2.0-linux-x64.tar.gz` | Vulkan / OpenGL ES 3（SDL3） |
| 网页 | `MiniBIM-v0.2.0-web.zip` | WebGPU / WebGL 2（用 HTTP 服务打开这个文件夹） |

### 新内容

**模型**（移植自 BIMCraft `crates/core`）
- 标高、轴网、墙（分层的类型、接头、洞口）、楼板、天花板、屋顶（迹线与拉伸）、房间与房间分隔线、门、窗、族与构件（公式，扫掠、旋转与空心形体）、材质
- 每次编辑都是可撤销的命令；项目存为 `.minibim`，与 BIMCraft 的 `.bimcraft` 格式相同，可以互相打开
- 三维视图由 SMLib 实体内核建模；各标高的平面（剖切填充、单线字、拾取）
- IFC：导出 IFC4，导入 IFC2x3 / IFC4
- 只读打开 Revit 项目（`.rvt`）：墙、楼板、天花板、屋顶、门窗、房间与柱，并列出没带进来的内容。
  Revit 读取器是 Apache-2.0 许可（移植自 BIMCraft 的 `crates/rvt`，含 rvt-rs 的代码），MiniBIM 其余部分为 MIT

**界面**（移植自 BIMCraft `crates/ui-egui`）
- 功能区，可停靠或浮动的特性与项目浏览器面板（浮动或紧凑布局），快速访问工具栏
- 放置工具（捕捉、预览、选项栏）；修改工具：窗选与交叉选、拖动、夹点、移动、复制、旋转、镜像、对齐、修剪、拆分、偏移
- 类型属性、族类型、材质对话框；楼板、天花板、屋顶边界的草图模式
- 开始页、最近打开、自动保存与恢复、设置、两个字母的快捷键、把文件拖进窗口打开
- 英文、简体中文、西班牙文、葡萄牙文

**其余选项卡**
- 结构：梁、独立基础与条形基础、结构柱
- 卫浴、电气、防雷、数据：管道、风管、线管、桥架等 run 与它们的设备
- 体量：体量、体量楼层、按面生成墙楼板屋顶、放样
- 注释：尺寸、文字、高程点、标记、详图线、填充区域、测量
- 视图：可见性 / 图形替换、平面视图与复制、视图样板与过滤器、明细表（CSV）、剖面、立面、图纸与视口
- 管理：项目参数、线宽、对象样式、线样式、线型图案、填充图案（导入导出 PAT）、清除未使用
- 插入：链接模型（`.minibim`、`.bimcraft`、`.ifc`）、从文件插入、DXF 导入与链接（图层、颜色、线型、捕捉）、
  点云（PTS、XYZ、PLY、LAS、E57），在三维视图与平面中显示并可捕捉

**平台**
- Linux 版（SDL3，Vulkan / OpenGL ES 3）与网页版（Emscripten，WebGPU / WebGL 2）；CI 编译、测试并打包三个版本

### 还没有的

- 剖面与立面里还不显示点云；还不读 LAZ、ReCap 与 DWG（请另存为 LAS、E57 或 DXF）
- 楼梯、坡道、栏杆、组、阶段与设计选项还没移植
- 已完成与待做的完整列表见 [docs/PLAN.md](https://github.com/CHMOSE023/MiniBIM/blob/main/docs/PLAN.md)
